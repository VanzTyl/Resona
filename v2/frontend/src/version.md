# Resona Frontend Version History

## 1.0.0 (2026-07-14)
- Initial release
- SPA with hash-based routing and auth guard
- Spotify OAuth login and callback handling
- Infinite scroll feed with friend activity cards
- Emoji reaction panel with auto-message trigger
- User search and friend request management
- Chat thread list and message history view
- Dashboard with listening stats and top artists
- Profile editing (display name, avatar URL)
- Bottom navigation bar with active state
- Skeleton loading states for all async content
- Toast notification system
- Accessible modal component
- Responsive dark theme design system
- Netlify SPA redirect configuration
